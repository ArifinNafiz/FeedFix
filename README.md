# FeedFix

FeedFix is a browser-based Shopify CSV validator and cleanup tool.

## Features
- Upload and preview Shopify product CSV files.
- Validate product data for common import issues.
- Get explanations and suggested corrections.
- Review and approve corrections before applying them.
- Export your cleaned CSV file.

## How to use
1. Open FeedFix in your browser.
2. Choose whether you're importing new products or updating existing products.
3. Upload your Shopify CSV file.
4. Review the detected issues.
5. Apply or approve corrections as needed.
6. Download your cleaned CSV.

## Privacy
Your uploaded CSV is processed in your browser. FeedFix does not send your product data to a FeedFix server.

## Built with
HTML, CSS, JavaScript and Papa Parse.
